# 装好之后怎么跑

包里三个可执行文件，各自独立，不需要安装步骤，解压到任意目录即可。

| 文件 | 是什么 | 怎么起 |
|---|---|---|
| `fmnr-ui` | 图形界面（双栏 + 目录树 + 统一预览 + 白板） | 双击，或命令行直接跑 |
| `fmnr` | 命令行入口，和界面走同一套卷与工具表 | `fmnr --help` |
| `fmnr-ai` | MCP / HTTP 服务端 | 见下面两节 |

## 中文字体

界面启动时从系统找一份 CJK 字体（Windows 上实测用 `simhei.ttf`）。
**找不到不会崩**，但所有中文会变成方块，而且程序会在状态栏说明这一点——
看到方块就是这台机器缺字体，不是程序坏了。

## 插件（可选）

预览面板的扩展插件从**配置目录**加载，不从 exe 旁边找：

- Windows：`%APPDATA%\fmnr\plugins\`
- Linux：`~/.config/fmnr/plugins/`

把包里的 `plugins/md-outline/`（含 `plugin.json` 与 `.wasm`）整个复制到上面那个目录下面，
重启界面即生效。这个目录不存在是正常状态（等于没装插件），坏插件只会记一条警告、
不挡启动——警告显示在状态栏。

## 当 MCP server 用（stdio）

给支持 MCP 的客户端这样配：

```json
{
  "mcpServers": {
    "fmnr": { "command": "/绝对路径/fmnr-ai" }
  }
}
```

参数面就这一个入口，不需要额外配置。stdout 是**纯 JSON**，
挂载失败一类的诊断走 stderr，不会混进契约里。

## 当 HTTP 服务用

```
fmnr-ai --serve 127.0.0.1:8787
```

`--serve` 后面**必须跟地址**（`HOST:PORT`），不给就报错而不是猜一个端口。
默认只允许绑回环地址；要让局域网里别的机器访问，得显式加 `--allow-remote`——
不带这个开关就默认对全网开放，是不该有的默认值。
`fmnr-ai --help` 会把这些打印出来。

## 命令行批量

`fmnr batch` 吃 NDJSON（一行一个请求）、吐 NDJSON（一行一个结果），
一行坏了不中断其余的，有失败则退出码非 0、汇总走 stderr。
实测比逐个调用的路径快 18.2×。

## 已知的边界（不是 bug 清单，是这一版没做的事）

- **SSH/SFTP 卷**：代码与契约测试在，但**没有在界面上真点过**（缺一台可连的主机）。
- **只读卷上的写操作**返回的错误码还是 `INTERNAL_ERROR`，没换成专门的 `Unsupported`。
- **同进程多 OS 窗口**没做：现在一个进程一个窗口。多视口本身在本机验证过可用
  （3.1 MB/额外窗口，10 窗口裸账 92 MB），但每窗口独立状态要先把界面层重构一遍。
- **不碰系统文件管理器**：不做 `IThumbnailProvider`/`IContextMenu` 这类 COM 注册，
  不 `ShellExecute` 起程序（一律自己 `CreateProcess`），默认也不写 `HKLM`。
  默认程序登记只写 `HKCU` 下自己的那一项，且可逆。
- **包更新只列不跑**：「可升级」那张表读 winget，但升级命令只复制到剪贴板，不代执行。
